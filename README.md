# UI-design-with-figma
Create a modern, professional, responsive UI/UX design for an AI-powered student application called StudyAI – Your AI Study Assistant. Use a minimal purple and blue gradient theme, white background, rounded cards, Poppins or Inter typography, and clean spacing. Create six screens: (1) Welcome with logo, tagline, Get Started and Login; (2) Login/Signup with name, email, password and Google login; (3) Dashboard with AI Study Planner, Study Plan, Learning Resources, Progress Tracker and AI Chatbot; (4) Study Plan with timetable, subject list, task checklist and progress bar; (5) Learning Resources with search, notes, videos and practice questions; (6) AI Chatbot with message bubbles and input. Use reusable components, Auto Layout and responsive design principles. Make it look like a real professional student portfolio application.
